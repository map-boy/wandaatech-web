Database Tables You Need

These 4 tables must exist in your Supabase project before anything works.

TablePurposeKey columns
competitionsStores each challengeid, title, status, deadline, max_submissions_per_day
ground_truthThe secret answer keyrow_id, true_label, difficulty_tier, adversarial, competition_id
registrationsStudent sign-upsdisplay_name, email, type, token
submissionsEvery scored submissionusername, final_score, competition_id, created_at
SQL — Create all tables 
-- competitions
CREATE TABLE competitions (
  id                      uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  title                   text NOT NULL,
  summary                 text,
  description             text,
  dataset_url             text,
  rules                   text,
  prize                   text,
  tags                    text[],
  deadline                timestamptz,
  status                  text DEFAULT 'open',
  participants            int DEFAULT 0,
  max_submissions_per_day int,
  benchmark_score         numeric,
  phase                   text,
  max_score_cap           numeric DEFAULT 92,
  weight_accuracy         numeric DEFAULT 0.45,
  weight_f1               numeric DEFAULT 0.30,
  weight_code             numeric DEFAULT 0.25,
  created_at              timestamptz DEFAULT now()
);

-- ground_truth (the secret answer key)
CREATE TABLE ground_truth (
  id              uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  competition_id  uuid REFERENCES competitions(id) ON DELETE CASCADE,
  row_id          text NOT NULL,
  true_label      text NOT NULL,
  difficulty_tier text DEFAULT 'medium',  -- easy | medium | hard
  adversarial     boolean DEFAULT false,
  column_weight   numeric DEFAULT 1.0
);

-- registrations
CREATE TABLE registrations (
  id           uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  display_name text NOT NULL,
  email        text UNIQUE NOT NULL,
  university   text,
  type         text DEFAULT 'individual',
  members      text[],
  token        text UNIQUE,
  team_token   text,
  team_name    text,
  group_id     uuid,
  competition_id uuid,
  created_at   timestamptz DEFAULT now()
);

-- submissions
CREATE TABLE submissions (
  id               uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  competition_id   uuid REFERENCES competitions(id),
  registration_id  uuid,
  username         text NOT NULL,
  group_id         uuid,
  model_name       text,
  accuracy_score   numeric,
  f1_score         numeric,
  code_score       numeric,
  composite_raw    numeric,
  final_score      numeric,
  adversarial_bonus numeric DEFAULT 0,
  per_class_f1     jsonb,
  column_audit     jsonb,
  feedback         text[],
  row_results      jsonb,
  created_at       timestamptz DEFAULT now()
);
02

Create a Competition in Admin Panel

🔐
Go to /admin Enter your admin password → click "Enter Panel"
↓
➕
Competitions tab → "New Competition" Fill in title, summary, description, prize, deadline, tags, dataset URL, rules
↓
💾
Save — note the competition ID Go to Supabase → competitions table → copy the uuid from the id column
↓
📤
Upload dataset to Supabase Storage Storage → create bucket "datasets" → upload your train.csv + test.csv → copy public URL → paste in dataset_url field
⚠️ The dataset_url is what students download to build their models. It should be the training data only — NOT the answer key.
03

Insert Ground Truth via SQL

No CSV file needed. After creating your competition, run this SQL directly in Supabase. Only change the UUID at the top and the VALUES rows with your actual labels.

ColumnTypeRequiredDescription
row_idtextRequiredMust exactly match row_id in student submissions
true_labeltextRequiredCorrect class label — use lowercase
difficulty_tiertextOptionaleasy / medium / hard — affects score weighting
adversarialbooleanOptionaltrue = bonus row, not counted in base score
column_weightnumberOptionalDefault 1.0 — raise for more important rows
SQL — paste UUID once, edit VALUES 
-- Step 1: get your competition UUID
SELECT id, title FROM competitions;

-- Step 2: paste UUID once at top, then fill in your labels
WITH comp AS (
  SELECT 'YOUR-COMP-UUID'::uuid AS id
)
INSERT INTO ground_truth
  (competition_id, row_id, true_label, difficulty_tier, adversarial, column_weight)
SELECT comp.id, v.row_id, v.true_label, v.difficulty_tier, v.adversarial, v.column_weight
FROM comp, (VALUES
  -- (row_id, true_label, difficulty, adversarial, weight)
  ('1',  'healthy',       'easy',   false, 1.0),
  ('2',  'blight',        'medium', false, 1.0),
  ('3',  'rust',          'hard',   false, 1.5),
  ('4',  'streak_virus',  'medium', false, 1.0),
  ('5',  'healthy',       'easy',   true,  1.0),  -- adversarial bonus row
  ('6',  'blight',        'hard',   false, 2.0),
  ('7',  'healthy',       'easy',   false, 1.0)
) AS v(row_id, true_label, difficulty_tier, adversarial, column_weight);

-- Step 3: verify count matches your test set
SELECT count(*) FROM ground_truth WHERE competition_id = 'YOUR-COMP-UUID';
🔒 Students never see this data. The ground_truth table should have RLS enabled in Supabase so only service_role can read it — the scoring API uses service_role key, not the public anon key.
⚠️ To clear ground truth and start over for a competition: DELETE FROM ground_truth WHERE competition_id = 'YOUR-UUID'; then re-insert.
04

Scoring Formula Explained

Final Score = min( Accuracy × 0.45 + F1 × 0.30 + Code × 0.25 + Adversarial Bonus, 92)
Score is capped at 92% by default — no one gets 100%. All weights are configurable per competition.
ComponentWeightHow it's calculated
Accuracy45%Weighted by difficulty_tier (easy=1×, medium=1.5×, hard=2×)
Macro F130%Average F1 across all classes
Code Mastery25%8 metadata columns present in submission CSV
Adversarial Bonus+2ptsCorrect on rows where adversarial=true
Code Mastery columns (all 8 must be in the student CSV)
columns
confidence, model_name, preprocessing_steps, feature_count,
validation_strategy, used_cross_validation,
handled_class_imbalance, train_test_split_ratio

07

Leaderboard View (SQL)

The leaderboard reads from a view, not the raw submissions table. This view shows each student's best score only. Run this once in Supabase SQL editor.

SQL — Create leaderboard view 
CREATE OR REPLACE VIEW leaderboard AS
SELECT DISTINCT ON (username, competition_id)
  id,
  username,
  model_name,
  accuracy_score   AS accuracy,
  f1_score,
  code_score,
  final_score,
  created_at       AS submitted_at,
  competition_id,
  group_id,
  NULL::text          AS team_name,
  ROW_NUMBER() OVER (
    PARTITION BY competition_id
    ORDER BY final_score DESC
  ) AS rank
FROM submissions
ORDER BY username, competition_id, final_score DESC;
08

Daily Submission Limit

Set max_submissions_per_day on the competition row to limit how many times a student can submit per day. NULL = unlimited.

SQL 
-- Set limit to 3 per day:
UPDATE competitions
SET max_submissions_per_day = 3
WHERE id = 'YOUR-COMP-UUID';

-- Remove limit:
UPDATE competitions
SET max_submissions_per_day = NULL
WHERE id = 'YOUR-COMP-UUID';
✅ The limit is enforced server-side in route.ts — students cannot bypass it by clearing localStorage or using a different browser.
08

Full Launch Checklist

  • Tables created — competitions, ground_truth, registrations, submissions all exist in Supabase
  • Leaderboard view created — run the SQL from Step 6
  • Env vars set — NEXT_PUBLIC_SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY in .env.local
  • Competition created in Admin Panel with title, deadline, status = open
  • Dataset uploaded to Supabase Storage, URL pasted into competition dataset_url field
  • Ground truth inserted into ground_truth table with correct competition_id
  • Daily limit set on competition (e.g. 3/day)
  • Test submission done — submit a CSV manually, verify score appears on leaderboard
  • Notebook cell shared with students from Admin → Notebook Cell tab
  • Students can register at /competitions → Register tab
